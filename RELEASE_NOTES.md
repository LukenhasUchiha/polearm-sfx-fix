# Polearm SFX fix 1.1.0

English | [Português (Brasil)](RELEASE_NOTES.pt-BR.md)

I made this project with an AI to restore missing weapon sounds in BT4 attack animations. I tested it in game and confirmed that polearm sounds returned.

**I am not a modder, I do not know programming, and I will not maintain this project or release updates.** I am sharing the source for anyone who wants to continue it.

Download **PolearmSFXFix-1.1.0.zip** for Vortex installation. No Script Extender, Mod Fixer, or Toolkit is required. The README explains the bug, the fix, installation, and tested coverage.
