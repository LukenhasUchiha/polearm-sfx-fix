# Polearm SFX fix 1.1.0

[English](RELEASE_NOTES.md) | Português (Brasil)

Fiz este projeto com uma IA para restaurar sons de armas ausentes nas animações de ataque do BT4. Testei em jogo e confirmei o retorno do som das armas de haste.

**Não sou modder, não sei programação e não vou manter o projeto nem lançar atualizações.** Disponibilizo o código-fonte para quem quiser dar continuidade.

Baixe **PolearmSFXFix-1.1.0.zip** para instalar pelo Vortex. Não precisa de Script Extender, Mod Fixer nem Toolkit. O README explica o bug, a correção, a instalação e a cobertura testada.
